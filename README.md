## Sobre o projeto

O **monko finance** é um aplicativo mobile de finanças pessoais que reúne contas, cartões e corretoras em uma única tela por meio do Open Finance, interpreta esses dados com um assistente de inteligência artificial e acompanha o usuário com uma trilha de educação financeira gamificada.

Consolidar saldo já é comum no mercado brasileiro. O que o monko propõe é responder o que fazer com aquele saldo, em linguagem simples, e ensinar o usuário a chegar sozinho nessa resposta ao longo do tempo.

Projeto acadêmico desenvolvido para o CP4 — Idealização do App, da disciplina de Mobile Development & IoT.

## Tecnologias

- React Native com Expo
- TypeScript
- expo-router

## Como executar

### Pré-requisitos

- Node.js 20 ou superior
- Expo Go instalado no celular, ou emulador Android / simulador iOS

### Passo a passo

```bash
# clonar o repositório
git clone https://github.com/VitorEskes/fiap-cp4-mobile.git
cd fiap-cp4-mobile

# instalar as dependências
npm install

# iniciar o servidor de desenvolvimento
npx expo start
```

Leia o QR Code com o Expo Go, ou pressione `a` para abrir no Android e `i` para abrir no iOS.
